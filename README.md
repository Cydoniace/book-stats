# 📚 Книжная статистика

Сайт для учёта прочитанных книг и фанфиков со статистикой по годам. Он заменяет Google-таблицу
(листы «книги24–26», «ff24–26», «stats», «to read»).

**Разделы:** журнал книг с поиском · статистика за год (по месяцам, оценки, эпохи, языки, страны, жанры,
источники, любимые и нелюбимые книги месяца) · фанфики · to read со случайным выбором книги · сравнение лет ·
резервная копия и импорт.

Технологии: Vite + React + TypeScript, графики Chart.js, данные в Supabase (бесплатный тариф).
Хостинг — GitHub Pages.

## Как выложить сайт (один раз, примерно 15 минут)

### 1. База данных Supabase

1. Зарегистрируйтесь на <https://supabase.com> (можно через GitHub) и нажмите **New project**.
   Придумайте название и пароль базы, регион выберите ближайший, например Central EU (Frankfurt).
2. Когда проект создастся, откройте **SQL Editor → New query**, вставьте всё содержимое
   файла [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**. Появятся таблицы `books`, `fanfics` и `toread`.
3. Создайте пользователя: **Authentication → Users → Add user → Create new user**. Введите email и пароль,
   отметьте *Auto Confirm User*. С этими данными вы будете входить на сайт.
4. Запретите посторонним регистрироваться: **Authentication → Sign In / Providers**, выключите *Allow new users to sign up*.
5. Скопируйте адрес и ключ: **Project Settings → API** (или **Data API**), нужны *Project URL* и ключ
   *anon public*.

### 2. GitHub Pages

1. Создайте на <https://github.com> новый **публичный** репозиторий, например `books`.
2. Загрузите в него файлы проекта: **Add file → Upload files**, перетащите всё содержимое папки,
   кроме `node_modules` и `dist`, затем **Commit changes**.
3. Откройте в репозитории файл `public/config.js`, нажмите ✏️ и впишите адрес и ключ из шага 1.5:
   ```js
   window.APP_CONFIG = {
     supabaseUrl: 'https://xxxxxxxx.supabase.co',
     supabaseAnonKey: 'eyJhbGciOi...',
   };
   ```
   Ключ *anon* можно хранить в открытом виде: без входа по паролю он ничего не даёт, данные защищены
   правилами доступа (RLS) в базе.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
5. Откройте вкладку **Actions** и дождитесь зелёной галочки (1–2 минуты). Сайт будет доступен
   по адресу `https://<ваш-логин>.github.io/books/`.

Дальше любое изменение в репозитории, даже правка файла через сайт GitHub, автоматически
пересобирает и выкладывает сайт.

### 3. Перенос данных из Google-таблицы

Войдите на сайт, откройте **Данные → Импорт** и выберите файл `import-from-sheet.json`
(его собирает скрипт `tools/sheet_to_json.py`). Режим «заменить всё» удалит текущие записи и загрузит файл.

> ⚠️ Не кладите этот JSON и резервные копии в репозиторий: репозиторий публичный.
> В `.gitignore` они уже исключены.

## Как пользоваться

- **Книги → «+ Книга».** Поля «автор», «жанр», «откуда», «страна» подсказывают уже введённые значения.
  «Новый автор» отмечается сам, если этого автора ещё нет в базе. Эпоха считается по году издания
  (до 1700 — век, затем 1700/1750, дальше десятилетия), её можно поправить вручную.
- **Книга месяца:** в карточке книги выберите «♥ любимая» или «✗ нелюбимая». В каждом месяце может быть
  только одна книга каждого вида.
- **Фанфики:** жанровые метки пишите через пробел или запятую. Группы считаются автоматически, синонимы
  (everyday/эвридэй, omegaverse/омегаверс, werewolf/оборотни…) объединяются. Список групп находится
  в `src/lib/stats.ts` → `FF_GENRES`.
- **Цвета годов:** 2024 — мятный 🌿, 2025 — небесный 🫧, 2026 — розовый 🌸, дальше по кругу лавандовый 🪻,
  персиковый 🍑, лимонный 🍋. Палитры — в `src/lib/theme.ts`. Выбранный год общий для «Книг», «Статистики» и «Фанфиков».
- **Данные → Скачать копию** — время от времени сохраняйте резервную копию.
- Новый год появляется сам: достаточно добавить первую книгу с этим годом.

## Демо-режим

Если `config.js` не заполнен, сайт работает без базы и хранит данные в браузере (localStorage).
Это удобно, чтобы посмотреть сайт до настройки Supabase.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Пересобрать файл импорта из таблицы. Выгрузите листы в CSV по ссылкам вида
`https://docs.google.com/spreadsheets/d/<ID>/gviz/tq?tqx=out:csv&gid=<GID>` и сохраните под именами
`books24.csv`, `ff24.csv`, `stats24.csv`, …, `toread.csv`, затем:

```bash
python3 tools/sheet_to_json.py <папка с csv> import-from-sheet.json
```
